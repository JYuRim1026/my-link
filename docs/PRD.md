# 📄 [PRD] 마이링크 (MyLink) - 멀티 링크 & 바이오 프로필 서비스 기능 정의서

---

## 1. 프로젝트 개요 (Overview)

### 1.1 서비스 명칭
- **마이링크 (MyLink)**

### 1.2 서비스 목적
- 개인 크리에이터, 개발자 및 일반 사용자가 자신의 소셜 미디어, 기술 블로그, 포트폴리오, 프로젝트 링크를 한곳에 깔끔하고 감각적으로 모아 제공하는 **멀티 링크 & 바이오 프로필 서비스** (Linktree 클론).

### 1.3 아키텍처 및 구현 방식
- **프론트엔드**: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4
- **전역 상태 관리**: **Zustand** (`zustand` + `persist` 미들웨어 사용으로 `localStorage` 자동 동기화)
- **단계별 시연 진행 방식**: 시연 순서에 맞춰 **[Step 1: 로컬스토리지 연동 프로필 페이지]**를 우선 구축한 후, 차후 단계로 관리자 대시보드 및 통계 기능을 순차적 확장.

---

## 2. 타겟 사용자 (Target Audience)

1. **개인 크리에이터 및 인플루언서**: 소셜 미디어(유튜브, 인스타그램, 틱톡 등) 바이오에 다중 링크 제공 필요 사용자
2. **개발자 및 디자이너**: 깃허브 저장소, 기술 블로그, 포트폴리오, 이메일 문의를 커스텀 테마로 묶어 전달하려는 사용자
3. **일반 사용자**: 자신만의 개성 넘치는 멀티 링크 프로필을 빠르고 쉽게 작성/공유하려는 사용자

---

## 3. 사용자 시나리오 (User Scenarios)

### 🎬 시나리오 1: 개발자/크리에이터 '민수'의 프로필 생성 및 SNS 공유
- **페르소나**: 백엔드 개발자 민수 (자신의 깃허브, 기술 블로그, API 문서, 이메일 주소를 하나로 묶어 SNS 바이오에 게시하고 싶음)
- **사용자 흐름**:
  1. 민수는 마이링크 서비스(`/`)에 접속한다.
  2. 로컬스토리지에 저장된 프로필 데이터를 기반으로 원하는 테마(Nintendo 2001, Neo-Brutalism, Minimal 중)를 실시간으로 전환하며 미리본다.
  3. 아바타, 닉네임, 역할 배지(`Backend & Server Engineer`), 기술 스택 배지 및 주요 링크 목록이 적용된 완성형 프로필 페이지를 확인한다.
  4. 본인의 소셜 미디어(Instagram, X, GitHub) 바이오에 마이링크 프로필 주소를 공유한다.

### 🎬 시나리오 2: 일반 방문자 '지은'의 크리에이터 프로필 방문 및 커뮤니케이션
- **페르소나**: 개발 블로그 방문자 지은 (민수의 SNS 바이오 링크를 눌러 마이링크 프로필에 들어옴)
- **사용자 흐름**:
  1. 지은이는 스마트폰 모바일 브라우저로 민수의 마이링크 프로필 페이지에 접속한다.
  2. 모바일 화면에 맞춰 깨짐 없이 정돈된 반응형 레이아웃과 레트로/네오브루탈 디자인 요소를 열람한다.
  3. `COPY EMAIL` 버튼을 눌러 `"COPIED!"` 안내 피드백과 함께 클립보드에 이메일 주소를 즉시 복사한다.
  4. 관심 있는 "기술 블로그" 또는 "GitHub 저장소" 링크 카드를 클릭하여 외부 사이트로 새 탭 이동한다.

### 🎬 시나리오 3: 관리자 '민수'의 대시보드 링크 수정 및 라이브 프리뷰 (Step 2 확장 시나리오)
- **페르소나**: 프로필 정보를 실시간으로 수정하려는 사용자
- **사용자 흐름**:
  1. 민수는 관리자 대시보드(`/admin`)에 접속한다.
  2. 신규 포트폴리오 링크를 추가하고, 드래그 앤 드롭(또는 이동 버튼)으로 링크 노출 순서를 즉시 변경한다.
  3. 우측 모바일 라이브 프리뷰 캔버스에서 수정 사항이 실시간 렌더링되는 모습을 확인한다.
  4. 수정된 데이터는 Zustand + LocalStorage에 자동 저장되어 공개 프로필 페이지에 즉시 적용된다.

## 4. 단계별 시연 및 기능 요구사항 (Step-by-Step Feature Specs)

### 📌 [Step 1] 로컬스토리지 연동 프로필 페이지 (현재 시연 단계)
> **※ 참고**: 대시보드 및 통계/애널리틱스 기능은 포함하지 않고, 프로필 페이지 자체의 로컬스토리지 연동 및 동적 렌더링에 집중합니다.

- **URL 경로**: `/` 또는 `/profile`
- **주요 기능**:
  - `localStorage` 기반 프로필 데이터 및 링크 목록 동적 로드/저장
  - 테마 프리셋(Nintendo 2001, Neo-Brutalism, Minimal 등) 실시간 적용
  - 링크 클릭 시 해당 URL 이동 및 클립보드 이메일 복사 (`COPIED!` 토스트)
  - 소셜 링크 바 및 반응형 모바일~데스크톱 가변 레이아웃 지원

### 📌 [Step 2] 관리자 대시보드 (차후 시연 단계)
- **URL 경로**: `/admin`
- **주요 기능**:
  - 프로필 정보(아바타, 이름, 소개글, 역할 배지) 편집
  - 링크 C.R.U.D 및 순서 변경(드래그 앤 드롭/이동 버튼)
  - 실시간 라이브 모바일 프리뷰 캔버스 제공

### 📌 [Step 3] 통계 & 데이터 관리 (차후 확장 단계)
- 링크 클릭 수 측정 및 LocalStorage 기록
- 프로필/링크 데이터 JSON Export / Import 및 초기화(Reset) 기능
